# Hand-off: ICMNS logo

Context for continuing this work in another Claude Code conversation. All files referred to below are in this `logo/` folder; copy the whole folder into the working directory of the new conversation.

## Brief

Design a logo for **ICMNS, the International Conference on Mathematical Neuroscience**, for use on **www.icmns.org**. The starting inspiration was a brain tractography image: thin flowing fibres in red, green, yellow and blue on a dark background. The logo must contain a visible reference to mathematics, and the SVG must be generated by code, so that the curves are mathematically defined.

## Current design and its mathematics

- **Gyri and sulci** form a Turing pattern. They are a solution of the **Swift–Hohenberg equation**, u_t = r u − (1 + ∇²/k₀²)² u − u³, with r = 0.3 and a gyral wavelength of 2π/k₀ = 0.19 brain units.
  - It is solved pseudo-spectrally (semi-implicit FFT, dt = 0.5, 170 steps from noise) on the brain-shaped domain.
  - In the last 60 steps u is pinned negative outside the cortex, so the folds round off at the edge.
  - Each gyrus is drawn as nested level sets u = −0.12, 0.18 and 0.45. Specks smaller than 0.07 units are dropped.
- **Colour** follows the DTI tractography convention: each short piece of fibre is coloured by its direction (front–back, up–down, or one of two obliques).
- **Outline:** the default is a built-in implicit function (a hemisphere and a temporal lobe joined by a soft union, with a thin lateral (Sylvian) fissure cut into it). The outline can instead be taken from an image with `--mask`.
- **Cerebellum:** level sets of a curved coordinate, which give the folia, clipped to an ellipse.
- **Brainstem:** a bundle of parallel offsets of a Catmull–Rom spline in the shape of an **integral sign ∫**, tapered like the printed symbol. This is the explicit maths cue now that the equation has been removed.
- **Layering:** the cerebellum is drawn first. A filled silhouette of the cortex hides whatever lies behind it, then the cortex is drawn, then the ∫ sits on top with a dark halo.
- **Palettes:**
  - `cool` (the default): background #0b1021; fibres #4c8dff, #3fe0c5, #8fd8ff and #9b7bff.
  - `warm` (the original): background #1e1c1d; fibres #ef6b5f, #9fe07c, #e7ef7a and #3f9bd6.
- **Lettering:** "ICMNS" in DejaVu Sans Bold, with the subtitle "INTERNATIONAL CONFERENCE ON MATHEMATICAL NEUROSCIENCE" underneath. The text is converted to outlines, so the SVGs need no fonts.

## Files

| File | What it is |
|---|---|
| `make_logo.py` | Main generator (needs numpy, matplotlib, contourpy). Writes `<out>_logo.svg` (stacked, 1000 × 1080) and `<out>_mark.svg` (brain only, square). |
| `web_assets.py` | Builds the web set in `web/` from `icmns_logo.svg`. It compacts the SVGs from about 700 KB to about 80 KB by merging paths, simplifying the polylines and using relative coordinates. It also makes the header lockup, favicons, apple-touch icon, a 1200 × 630 `og-image.png` and `favicon.ico`. |
| `render.js` | Renders an SVG to PNG with Playwright and Chromium: `node render.js in.svg out.png W H`. Set `PLAYWRIGHT_PATH` and `CHROMIUM_PATH` if they are not on the default paths. |
| `make_logo.jl` | Julia port of `make_logo.py` (FFTW, Contour, and FileIO/ImageIO/ColorTypes for `--mask`). **It has never been run** (see below). |
| `icmns_text_paths.jl` | The outlined lettering as constants (`TITLE_D`, `SUB_D`), included by `make_logo.jl`. |
| `icmns_logo.svg`, `icmns_mark.svg`, `*_preview.png` | Current output: cool palette, seed 3. |
| `web/` | Web-ready files, with a `README.md` that has the HTML `<head>` snippet and an example header `<img>`. |
| `topview/`, `sideview_v2/`, `sideview_v3/` | Earlier versions, each with the script that made it. |

## How to run

```sh
python3 make_logo.py [--palette cool|warm] [--mask brain.png] [--seed N] [--no-cerebellum] [--out icmns]
python3 web_assets.py          # after make_logo.py; needs node + playwright
julia make_logo.jl [same flags]   # untested
```

- `--mask` accepts a PNG with transparency (the brain is the opaque part) or a silhouette on a plain background. The shape is scaled to the default brain box, keeping its aspect ratio. It has only been tested on a synthetic silhouette.
- `--seed` changes the folding pattern. Seed 3 was chosen by eye.
- A run takes about 10 s in Python.

## The Julia port has not been tested

The cloud sandbox could not download Julia, because the network policy blocks julialang.org. Daniele has Julia installed on their Mac (juliaup).

Install the packages once:

```sh
julia -e 'using Pkg; Pkg.add(["FFTW","Contour","FileIO","ImageIO","ColorTypes"])'
```

Points to check on the first run:
- The conditional `using FileIO, ColorTypes` inside a top-level `if`.
- The use of `fftfreq`, and `plan_fft` applied to a real array.
- Contour.jl's `contour(xs, ys, z, level)`, where `z` is indexed `[i, j] = (x[i], y[j])`.
- The broadcasting in `catmull_rom`.

Julia's RNG differs from NumPy's, so the folds will differ for the same seed. Try a few seeds. The port writes only the two main SVGs; `web_assets.py` (Python) builds the web set from them.
